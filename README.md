# 麻醉计算助手 · 1.1.2 测试版

[打开应用](https://joynjim583-creator.github.io/anesthesia-calculator/)

手机优先、可安装与离线使用的个人麻醉计算与临床速查工具。

## 本版新增：围术期血糖管理专题

- 首页 → 专题 → 术中评估 → 处理建议；可收藏，另有无需输入的处理速查。
- CPOC 2023、ADA 2026、SAMBA 2024 三条路径分开呈现，不混合阈值与目标。
- 干预阈值、皮下纠正、静脉输注、低血糖与原文定位；疑似急症、信息不明、已有胰岛素治疗等分别提示。
- 仅成人非妊娠辅助速查测试版，未经临床验收。不自动产生胰岛素剂量、泵速或处方；结合原文与本院方案使用。儿童、妊娠及DKA/HHS需专用路径。
- 摘要与规则支持离线，原文链接需联网。不上传用户提供的 PDF 全文。

## 保留的体重计算

统一输入身高、实际体重和性别，展示 BMI、标准体重、瘦体重、理想体重 IBW、预测体重和校正体重。六项公式沿用1.1.1；IBW为H−105，CBW＝IBW＋0.4×（W−IBW）。无TBW独立卡片，不恢复新患者按钮或搜索。

## 更新与隐私

保持原安装，联网打开设置 → 检查更新 → 确认1.1.2，等待离线资源就绪。新版准备完成后才切换，不强制中断当前计算；失败保留旧版。

患者参数只在设备内存，默认不保存历史、不上传、不写URL和日志；刷新/重开不恢复参数。收藏只保存工具ID，可同时收藏体重与血糖专题。托管平台可能产生访问日志。
