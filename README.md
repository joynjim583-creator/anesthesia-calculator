2026 AHA/ACC多学会指南为再确认版，推荐及图表沿用2024版。原文疑点与历史共识引述在相关页注明。保留体重、血糖及ISNCSCI专题；不采集心血管患者参数，不生成自动手术许可、桥接或剂量处方。

## 更新与隐私

保持原安装：设置 → 检查更新 → 确认1.3.0 → 等待离线资源已就绪。确认前旧参数和结果保留；确认后清空临时参数并保留收藏。患者参数仅在当前设备内存处理，不上传、不保存历史、不写入URL或日志。收藏仅保存在本机，托管平台仍可能记录访问日志。
