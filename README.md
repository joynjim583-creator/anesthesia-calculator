## 本版更新

按项目规范重置血糖专题。以CPOC 2023、ADA 2026住院章节及SAMBA 2024为依据，提供13个主题的背景、适用条件、处理步骤、原文定位和疑点说明；保留ADA 21个编号推荐条目及SAMBA表1的11项推荐强度与证据等级。

图表与正文步骤节选共19项，其中18项提供中文／原文整页对照。译图保留原行列、合并格、框体、箭头、分支、配色、数值、单位及脚注；不转置、重排或改成逐行卡片。SAMBA文献检索图保留原文并标明研究方法用途。中文不是官方版本。

支持100/150/200/300%缩放、双向滚动、切换语言保持倍率、关闭返回焦点及离线使用。三份原文共78页提取文本可按页核对。各文献的血糖目标、干预条件、药物建议和原文疑点分别显示，不合并为通用阈值或自动治疗算法。

## 更新与隐私

沿用原安装：联网打开设置 → 检查更新 → 确认1.3.2 → 等待离线资源已就绪。确认前旧参数和结果保留，确认后清空临时参数并保留收藏。

患者参数仅在当前设备内存处理，不上传、不保存历史、不写入网址或日志。收藏仅保存在本机；托管平台仍可能记录访问日志。血糖专题采用人工查阅方式，不采集血糖参数、不自动分类或生成给药剂量。
