## 围术期血糖：遇到情况，直接查处理流程

按用户反馈删除“开始术中评估”、参数表单和自动评估结果。首页按六种情况进入：术中发现血糖升高、需要静脉胰岛素输注、低血糖、日间手术高血糖、疑似DKA/HHS、围术期全程衔接。

每页提供中文处理步骤、复测与升级要求、相关流程与原文定位；加入CPOC图1、ADA图16.1原图、CPOC输注原表及处理步骤截图，配中文解读。明确区分文献原图、原表、原文截图与“中文整理·非原图”。原图可点开放大、缩放并横纵向滚动，可离线查看。

成人非妊娠临床速查测试版，尚未经临床验收，不自动生成处方；需核对原文、患者状态与本院方案。DKA/HHS是独立急症路径，不能当作普通高血糖纠正。

## 保留的功能

六项体重指标公式与1.1.2相同：BMI、SBW、LBW、IBW、PBW、CBW。IBW为H−105，CBW使用成人系数0.4。收藏支持体重与血糖专题，无TBW卡片、新患者按钮或搜索。

## 更新与隐私

保持原安装：设置 → 检查更新 → 确认1.1.3，等待离线就绪。更新不强制打断当前计算，下载失败保留旧版。

参数只在设备内存，不上传、不保存患者历史，不写URL或日志；刷新/重开不恢复。收藏仅保存工具ID。新血糖专题不收集患者参数。托管平台可能产生访问日志。
