# 麻醉计算助手 · 1.1 预览版

## 1.1.0 更新

移除“实际体重（TBW）”独立工具。保留 BMI、瘦体重所需的实际体重输入，其余公式不变。

现有五项工具：体质指数 BMI、标准体重 SBW、瘦体重 LBW、理想体重 IBW、预测体重 PBW。

## 从 1.0 更新

保持原安装，联网打开设置 → 检查更新 → 查看 1.1.0 说明 → 确认更新并重新打开。更新后确认版本为 1.1.0，工具列表为五项。离线资源就绪后可断网重新打开。

## 数据与部署

参数只在设备本地计算，默认不保存计算记录。收藏仅保存工具 ID。

当前为公式与交互核对预览版，公式适用范围及临床案例仍待核验。

仓库存放静态网站文件，GitHub Pages 从 main 分支根目录发布。releases/1.0.0 保留已发布版本；新界面与公式位于 releases/1.1.0。新版本先完整准备离线资源，经确认再切换。
