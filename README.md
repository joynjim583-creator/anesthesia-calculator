## 本版更新

新增“脊髓损伤神经功能评估”专题，依据ISNCSCI 2026第9版。包含感觉检查、运动检查、骶段功能、平面与AIS、特殊情况及ZPP六个入口，以及2026重点澄清、常见损伤模式和缩写说明。

纳入全文16份图表：3张编号图、非关键肌对照表、10个运动平面病例及评分表正反两页。中文翻译整理页配原文对照，非ASIA或出版社官方中文版；支持100/150/200/300%放大、横纵滚动及离线查看。病例数值格保留原图，不重新录入。未加入自动AIS分类或治疗处方。

体重指标BMI、SBW、LBW、IBW、PBW、CBW及血糖专题沿用1.1.4内容。
