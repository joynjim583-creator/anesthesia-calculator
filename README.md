# 麻醉计算助手 · 1.4.0 测试版

[打开应用](https://joynjim583-creator.github.io/anesthesia-calculator/)

## 本版更新

新增围术期输血与血液管理专题，整合用户提供的15份文献，按17个麻醉工作场景查阅114条意见；每条注明来源、适用条件、推荐语气／等级及原文页码。13组推荐差异并列，不设机构或国内外优先级；6项原文疑点单列。

图表保留原结构，支持中文／原文对照、100／150／200／300%缩放及双向滚动。本版为所选临床速查范围，含9份英文译表资源和17份中文原页资源；部分整合流程目前仅保留英文原页，应用中明确标注。全部326页有提取文本，141页附原文图像。

既有体重计算、血糖、神经、心血管专题保留。输血专题为人工查阅，不自动产生患者分类、输血方案或给药剂量。译文与临床内容待专业审核。

## 怎样使用输血专题

从首页进入“围术期输血与血液管理”，选择当前麻醉场景，先核对人群与适用条件，再并列阅读各文献意见；可按来源筛选，点击PDF页码核对原文。同一问题有不同推荐时进入“推荐差异对照”，不将不同条件的阈值混作统一方案。图表可点击放大，译表可切换原文，收藏保存在本机。

## 更新与隐私

沿用原安装：联网进入设置 → 检查更新 → 确认1.4.0 → 等待离线资源已就绪。首次下载图像需要时间。确认前旧输入与结果保留；确认后清空临时参数并保留收藏。患者参数仅在本机内存处理，不上传、不保存历史；收藏偏好可保存在本机。托管平台可能记录访问日志。
