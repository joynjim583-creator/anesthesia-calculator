# 麻醉计算助手 · 1.1.1

[打开计算器](https://joynjim583-creator.github.io/anesthesia-calculator/)

统一输入身高（cm）、实际体重（kg）和性别，点击“计算全部”，集中显示六项指标：BMI、标准体重 SBW、瘦体重 LBW、理想体重 IBW、预测体重 PBW、校正体重 CBW。

## 1.1.1 更新

- 移除新患者按钮，隐藏搜索栏并保留开发接口。
- 体重与体型分类直接打开汇总计算页，不再逐项进入。
- 实际体重仅保留输入，不恢复已移除的 TBW 独立结果。
- 新增成人 CBW＝IBW＋0.4×（W－IBW）。IBW 专指理想体重，沿用现有 H－105，不使用标准体重或预测体重替代。不含儿童系数 0.3。
- 删除适用范围与来源栏，保留公式与计算过程。
- 参数改变后清除旧结果；旧收藏迁移为体重综合计算收藏。

CBW 算例：170 cm / 70 kg → IBW 65.0 kg，CBW 67.0 kg。公式参考用户提供的[梧桐医学文章](https://mp.weixin.qq.com/s/HnDjM3VMGFKboERqOYtFfA)，IBW 沿用本项目公式。其余五项公式保持不变。

## 更新与隐私

保持原安装，联网打开设置 → 检查更新 → 确认 1.1.1 更新并重新打开。等待离线资源就绪后可断网重新打开。下载失败保留旧版，不在输入时强制刷新。

参数只在设备内存中计算，默认不保存计算记录。刷新不恢复输入，下一次计算需自行核对并替换表单参数。收藏仅保存工具 ID。

当前仍需核对公式适用范围及实际临床案例，工程测试不等于临床验证。

仓库存放静态网站文件，GitHub Pages 从 main 分支根目录发布。本地 app/ 对应仓库根目录。releases/1.0.0 与 releases/1.1.0 保留，新版位于 releases/1.1.1。
